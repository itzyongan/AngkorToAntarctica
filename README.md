# From Angkor to Antarctica

**One generation. One extraordinary journey. One country represented at the bottom of the world.**

[![Live Website](https://img.shields.io/badge/Website-Live-0b1f33?style=flat)](https://angkortoantarctica.live/)
[![Languages](https://img.shields.io/badge/Languages-English%20%7C%20Khmer-f2a900?style=flat)](#language-support)

**From Angkor to Antarctica** is a Cambodian Gen Z expedition initiative with an ambition to take Cambodian youth to the geographic South Pole.

The project aims to demonstrate what young Cambodians can achieve, represent Cambodia in one of the world's most remote environments, and bring the journey home through climate education, cultural exchange, and youth leadership.

🌐 **Website:** https://angkortoantarctica.live/

## Our Mission

This is a mission, not a holiday.

The expedition brings together four core objectives:

- **Youth Achievement** — Show that Cambodian young people can aspire to, plan, and accomplish extraordinary international challenges.
- **National Representation** — Put Cambodia on the map in an environment where it is rarely represented.
- **Environmental Awareness** — Connect the journey to climate change and environmental education.
- **Cultural Exchange** — Document the expedition and share it with Cambodian school and university students.

## The Challenge

The expedition concept includes skiing the final **111 km** (the Last Degree) to the geographic South Pole.

The website presents the following indicative planning figures:

| Item | Estimated Cost |
|---|---:|
| Last Degree expedition per person | US$81,000–90,000+ |
| Potential five-person expedition | US$400,000+ |
| Initial fundraising target | US$125,000 |

These are planning estimates, not confirmed quotes or secured funding. Specialist expedition packages exclude international flights, personal equipment, insurance, and preparation.

## What Cambodia Gets Back

The expedition is intended to create a lasting educational and cultural legacy in Cambodia.

Planned outcomes include:

- Presentations at 20 Cambodian schools and universities.
- A short documentary about the expedition.
- A social media series about climate change and Antarctica.
- A youth leadership programme focused on resilience, teamwork, and international ambition.
- A photographic exhibition in Phnom Penh.

## About This Repository

This repository contains the public-facing website for From Angkor to Antarctica.

The website is built using lightweight, browser-native technologies:

- **HTML5** — Page structure and content.
- **CSS3** — Responsive layout, styling, and typography.
- **Vanilla JavaScript** — Language switching and contribution interactions.
- **SVG** — Original Angkor Wat and Antarctic landscape illustration.

No frontend framework, package manager, or build process is required.

### Website Features

- Responsive single-page website.
- English and Khmer language support.
- Custom visual identity inspired by Cambodia and Antarctica.
- Interactive language switcher.
- Expedition mission and objectives.
- Expedition cost and fundraising breakdown.
- 90-day campaign timeline.
- Educational legacy and sponsorship information.
- Interactive contribution selector linked to WhyDonate.
- SEO metadata and social sharing previews.
- Accessibility features, including keyboard focus and reduced-motion support.

## Getting Started

The website is static and does not require dependency installation.

### 1. Clone the repository

\`\`\`bash
git clone https://github.com/itzyongan/angkortoantarctica.git
cd angkortoantarctica
\`\`\`

### 2. Run locally

Simply open `index.html` in your browser.

Alternatively, use Python's built-in HTTP server:

\`\`\`bash
python3 -m http.server 8000
\`\`\`

Visit:

http://localhost:8000
